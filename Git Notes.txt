Git & G
GitHub Notes
==================

Clone & Navigation
------------------

- Clone a repository:
= git clone <repository_link>
  (Clones a remote repository into your local system using any IDE terminal.)

- to enter in the folder of repo:
= cd <folder name> 

- List files in the directory:
= ls
  (Displays all files and folders.)

- List hidden files as well:
= ls -a




Status & Commit Workflow
------------------------

- Check repository status:
=  git status

- to stage(ready to commit) file: 
= git add <file_name>

- all changes ready to commit by this one line
= git add .  

-  commit the file (to save all the changes):
= git commit -m "some message" 



Push Changes to GitHub
----------------------


- to push changes directly to the GitHub repo:
= git push origin main 


Remote & Branch Management
--------------------------

- to push a new project directly to the GitHub: 
= git remote add origin <repo_link> 

- to verify remote:
= git remote -v 

- to check branch:
= git branch 

- to rename the branch:
= git branch -M <name> 

- - Push the main branch for the first time:
= git push -u origin main



Branch Commands 
--------------------------

- Create a new branch:
  git branch <branch_name>

- Switch to a branch:
  git checkout <branch_name>

- Create and switch to a new branch:
  git checkout -b <branch_name>

- Merge a branch into the current branch:
  git merge <branch_name>

- Delete a branch (locally):
  git branch -d <branch_name>

- Force delete a branch (if not merged):
  git branch -D <branch_name>

- Delete a branch on remote:
  git push origin --delete <branch_name>

- List all branches (local and remote):
  git branch -a

- Show which branch contains a commit:
  git branch --contains <commit_hash>
