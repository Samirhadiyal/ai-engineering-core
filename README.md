<table>
<tr>
<td>

This repository is my **personal Machine Learning learning journal** — a structured, topic-by-topic breakdown of every core ML concept, algorithm, and technique. Each folder contains **detailed notes**, **clean Python implementations**, and **real dataset experiments**.

The goal isn't just to run code — it's to deeply understand *how* and *why* every algorithm works, including building several from **scratch without libraries**.

> 💡 **Philosophy:** *"You don't truly understand something until you can build it from scratch."*
